# ☕ Coffee Page

Landing page de uma **cafeteria fictícia** desenvolvida com foco em **HTML, CSS e JavaScript puro**, criada para compor portfólio frontend.

O projeto explora layout moderno, responsividade, animações suaves e boas práticas de organização de código.

---

## 📸 Preview

> Projeto visual inspirado em cafeterias modernas, com estética escura, tipografia limpa e foco em experiência do usuário.

---

## 🚀 Tecnologias utilizadas

- **HTML5**
  Estrutura semântica e acessível

- **CSS3**
  - Flexbox e Grid Layout
  - Media Queries
  - Animações e transições
  - `backdrop-filter` (blur)

- **JavaScript (Vanilla)**
  - Menu hambúrguer responsivo
  - Controle de classes e animações

---

## ✨ Funcionalidades

- Header fixo com efeito de blur
- Menu hambúrguer animado (mobile)
- Navegação por âncoras com scroll suave
- Cards de menu com hover
- Seção de avaliações de clientes
- Mapa integrado (Google Maps)
- Layout totalmente responsivo

---

## 📱 Responsividade

O site foi pensado **mobile-first**, adaptando-se bem a:

- Smartphones
- Tablets
- Desktop
